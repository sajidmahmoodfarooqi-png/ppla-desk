Data & sharing

Save a backup

Everything you enter is kept in this browser on this device. Save a backup file regularly, and send it to coordinators on WhatsApp or email so they can load it.

Load a backup

Merge adds a coordinator's entries to yours and keeps the newer copy of anything edited on both sides. Replace wipes this device and loads the file as it is.

App version & updates

Updates reach phones over the internet until polling day. Entered data, photos and settings are never touched by an update.

Punjab colleges directory

Adds the 861 public colleges of Punjab (CIS Punjab list, with EMIS codes, district and division). Only colleges missing from this device are added; your entries are never overwritten.

Update units from a spreadsheet

In Excel, use Save As › CSV. Columns (any order, first row as headings): emis_code, name, district, division, members, contacted, support, rep, phone, notes. Colleges are matched by EMIS code, then by name. Blank cells leave the existing value alone. Tip: export the Units list first and edit that file.

Install on your phone

Android (Chrome): tap Install app at the top, or open the ⋮ menu and choose Install app / Add to Home screen.

iPhone (Safari): tap the Share button, then Add to Home Screen.

Clear this device

Removes every unit, outreach entry and team member stored in this browser. Save a backup first.
